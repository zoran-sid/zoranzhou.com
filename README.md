# zoranzhou.com

Zoran Zhou 的个人网站，记录技术学习、实践和日常生活。

访问：[zoranzhou.com](https://zoranzhou.com/zh-CN/) · [English](https://zoranzhou.com/en/)

网站包含文章、随记、书架、摄影和跑步旅行记录，支持中英文与文章订阅。
使用 Astro、TypeScript 和 Markdown 构建，由 Cloudflare Pages 托管。

## 本地运行

```sh
npm ci
npm run dev
```

## 构建

```sh
npm run lint
npm run build
```

静态文件输出到 `dist/`。
